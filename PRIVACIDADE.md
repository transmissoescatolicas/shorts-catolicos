# Política de privacidade — Shorts Católicos

Esta aplicação é usada apenas pelo dono do canal de YouTube "Transmissões Católicas" para publicar automaticamente os seus próprios vídeos.

- A aplicação pede só a permissão de **enviar vídeos** para o canal do próprio dono (`youtube.upload`).
- Não recolhe, não guarda e não partilha dados de outras pessoas.
- A autorização fica guardada como segredo encriptado no GitHub do dono e pode ser revogada a qualquer momento em https://myaccount.google.com/permissions.
